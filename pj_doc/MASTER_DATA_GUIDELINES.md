# 商品マスタ登録ガイドライン

## 基本原則

### ✅ 推奨登録方法
```
品名: 牛用配合飼料
型式: CF-2000  
規格: 20kg袋
メーカー: ○○飼料株式会社
```

### ❌ 避けるべき登録方法
```
品名: 牛用配合飼料 CF-2000 20kg袋  # 全部入り
型式: (空白)
規格: (空白)
```

## フィールド別登録ルール

### 品名（product_name）
- **商品の基本名称のみ**記載
- 型式・規格・容量は含めない
- 例：「牛用配合飼料」「豚用飼料」「鶏用配合飼料」

### 型式（model_number）
- **メーカー固有の型番・品番**
- 例：「CF-2000」「PF-150」「ABC-123」

### 規格（specification）
- **容量・サイズ・仕様**
- 例：「20kg袋」「1t袋」「粒状」「ペレット」

### メーカー（manufacturer）
- **正式会社名**
- 例：「○○飼料株式会社」「△△農業協同組合」

## AI価格抽出への影響

### 適切な登録の場合
```
AI抽出: "牛用配合飼料 CF-2000"
マスタ: 品名="牛用配合飼料", 型式="CF-2000"
→ 高精度マッチング（90点以上）
```

### ファジー登録の場合
```
AI抽出: "牛用配合飼料 CF-2000"  
マスタ: 品名="牛用配合飼料 CF-2000 20kg袋"
→ 中精度マッチング（70-80点）
```

## 既存データの整理方針

### Phase 1: 現状把握
- ファジー登録商品の洗い出し
- 登録パターンの分類・集計

### Phase 2: 段階的整理
- 新規登録から適切な方法に統一
- 既存データは影響範囲を考慮して段階的に整理

### Phase 3: 運用定着
- 登録時のバリデーション強化
- 定期的なデータ品質チェック
