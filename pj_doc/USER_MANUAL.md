## システム概要

デジタル価格表システムは、商品の価格情報を管理し、承認ワークフローを通じて価格表を作成するシステムです。

### 主な機能
- **商品マスタ管理**: 商品情報と価格履歴の登録・編集
- **承認ワークフロー**: 申請・承認・却下の管理
- **デジタル価格表**: 指定月の価格表表示・Excel出力
- **マスタメンテナンス**: 畜種・分類・メーカーの管理

## 基本操作

### ナビゲーション
左側のメニューから各機能にアクセス：
- 📦 **商品マスタ管理**: 商品の登録・編集
- 📝 **承認ワークフロー**: 申請の承認・却下
- 📊 **デジタル価格表**: 価格表の表示・出力

### 検索機能
各画面で商品名・メーカー・商品コードで検索可能
大量データは20件ずつ表示（デジタル価格表は200件）

## 商品マスタ管理

### 商品一覧
- 有効な商品のみ表示
- 検索機能
- 商品詳細へのリンク

### 商品登録・編集

#### 基本情報入力
1. **商品コード**: 9桁の数字（任意）
2. **畜種**: 必須選択
3. **分類**: 必須選択  
4. **メーカー**: 必須選択
5. **商品名**: 必須入力
6. **その他**: 型番・仕様・送料等

#### 価格履歴登録
1. **適用年月**: YYYY/MM形式で入力
2. **仕切価格**: 数値または「都度見積」
3. **県連価格**: 自動計算または手入力
4. **改定理由**: 任意入力

####　申請
- **申請**: 承認待ちに移行

### 商品コピー
既存商品の基本情報をコピーして新規作成

## 承認ワークフロー

### 申請一覧
- 承認待ちの申請を表示
- 申請種別（新規・変更・削除・再申請待ち）
- 検索・フィルタ機能

### 申請詳細・承認
1. **詳細確認**: 変更内容の差分表示
2. **承認**: 申請内容を本データに反映
3. **却下**: 再申請待ちに変更
4. **取消**: 申請を完全削除

### 一括承認
- 複数申請を選択して一括承認

### 承認のエラーチェック
- 自分の申請は承認不可

### 再申請
却下された申請は編集・再申請可能

---

## デジタル価格表

### 価格表表示
1. **対象年月選択**: プルダウンで選択
2. **表示**: 指定月時点の価格表
3. **並び順**: ドラッグ&ドロップで変更可能

### Excel出力
1. **Excel出力ボタン**: 価格表をExcelファイルでダウンロード
2. **ファイル名**: `価格表_YYYYMM.xlsx`

### 決裁書管理
- **アップロード**: 決裁書PDFの登録
- **ダウンロード**: 登録済み決裁書の取得

## トラブルシューティング

### よくある問題

#### ブラウザが開かない
手動で `http://127.0.0.1:8000/` にアクセス

#### 申請が承認できない
- 自分の申請は承認不可
- 申請状態を確認（再申請待ちは承認不可）

#### 価格履歴が登録できない
- 適用年月の形式確認（YYYY/MM）
- 過去日付の制限確認
- 重複チェック

#### データが保存されない
- 必須項目の入力確認
- ネットワーク接続確認
- ブラウザの再読み込み

### エラーメッセージ
システムからのメッセージは画面上部に表示されます：
- 🟢 **成功**: 緑色のメッセージ
- 🟡 **警告**: 黄色のメッセージ  
- 🔴 **エラー**: 赤色のメッセージ

## 付録

### ファイル構成
```
システムフォルダ/
├── デジタル価格表.exe       # メイン実行ファイル
├── config.ini              # 設定ファイル
├── db.sqlite3              # データベース
├── degital_value_list.xlsx # Excelテンプレート
└── media/                  # ファイル保存フォルダ
    ├── approval/           # 決裁書PDF
    └── ai_extract/         # AI抽出PDF
```

### 設定ファイル（config.ini）
```ini
[SYSTEM]
port = 8000
auto_browser = true

[DATABASE]
path = db.sqlite3

[FILES]
media_root = media
```

### バックアップ推奨
- **db.sqlite3**: データベースファイル
- **media/**: アップロードファイル
- **config.ini**: 設定ファイル
